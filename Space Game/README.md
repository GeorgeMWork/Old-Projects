# Space Game  

This was my first foray into independent game development and naturally fell apart at the first hurdle. Due to my intention of having it be a multiplayer game, I decided it would be better for me to get a better understanding of netcoding before continuing development. However, I have lost interest in continuing this project.  

As it stands, it has an interesting movement system, whereby the player can stick themselves to both walls and floors, mimicking magnetized movement in a zero-g environment.
