# Card Game  
This project was intended to be a rigidly turn-based card game. Unlike others, it made use of a speed statistic that allowed for cards to be played out of order. For example, the player selects three cards to be played during their turn against an enemy which selects two. The player might have two of their cards execute before the enemy's first,
then the enemy plays their cards, then the player uses their final card, ending the sequence.  

This could happen in any such order depending on how the player character was designed, which was intended to change during gameplay. Ultimately, I decided that this game filled no particular niche that was worth filling.
